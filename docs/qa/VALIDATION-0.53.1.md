## Regression coverage

- Scoped nested directories preserve eight accepted discovery notes, five source
  paths and an early nonadjacent source span on the final report/writer wire.
- The same saved journal is reopened on a smaller model/context. Required source
  remains whole and optional content becomes explicitly deferred.
- A real accepted recall request survives close/reopen, maps its old reference
  into a compatible execution, and reaches another Gateway invocation after a
  model switch. Applying the request twice adds no read, grant or spending.
- Foreign, forged, stale, quarantined and already-visible recall requests fail
  closed. Broad branches that exceed the page cap or working window are rejected
  before saving an unusable pending request.
- Host-only journal metadata is excluded from the model working-window limit.
  A 600-ID journal fits a 1,024-byte semantic directory window. An exact minimum
  preserves required whole pages when a coarse shrink step would undershoot.
- Native calls retain prior user constraints across reload/model changes, honor
  explicit source selection beyond four ranked pages, and page beyond the first
  24 source addresses. Document extraction receives prior user criteria while
  accepting quotations only from its exact section.
- Retained-only citation paths and disjoint windows reach independent claim
  source evidence. Writer notes cannot satisfy a reviewer evidence ID.
- Pending context requests cannot pass normal, recovery or manual publication
  entry points. Optional diagnostic failure cannot reject or refund inference.
- The AST audit classifies 17 registered roles across 14 production call origins.

## Bounded local-model observation

One stock architecture-report request used the real `qwen3:4b` Ollama provider,
the normal resource/context/gateway gates and a clean synthetic five-file
workspace. Its ten-call synthetic prelude contained eight accepted architecture
notes and two child calls, all charged: 22,980 units, 13 repository operations,
127,135 source bytes. The task limits were 40 calls / 250,000 units / 1,800
seconds / 1,000 repository operations / 64 MiB source. The single report request
had the existing maximum three bounded attempts; no allocation grants occurred.

The first live attempt was accepted in 20.55 seconds: 12,782 input and 343 output
tokens, settling to 13,125 units. Total spending became 36,105 units / 11 calls.
Source spending and all 13 source-operation receipts remained unchanged. Eleven
preservation checks passed, and receipt chains verified. The actual model wire
matched its committed descriptor and contained all eight notes, all five paths
and the earlier source anchor, with zero deferred pages.

**Negative semantic result:** the overview copied an unrelated Marigold dummy
summary from the conversation test fixture. The model cited valid files but did
not use the late source anchor or produce a diagram. That dummy came from the
synthetic parent fixture, not another user session. This proves delivery and
citation admission, not successful task synthesis. The original response is
retained; it is not replaced by a passing label.

`/var/folders/fy/x8qdt8yx3mn57b2pmjj6c0zc0000gn/T/tmpfvv7skxs/live-proof`.
Its manifest, outcome, response, exact wire and provisional report are retained.

The fixture contains marker functions without demonstrated inter-file call

## Broader saved-task checks

The first full run executed 1,711 Python tests in 482.677 seconds and found two
integration regressions. All 30 other release, Node, browser, packaging and
isolated VS Code gates passed. The intermediate package is retained at
`/private/tmp/Sutra-0.53.1-memory-candidate-1.vsix`, SHA-256
`695e15dc967bc92dd133323f15251dbffb7ad9d7dc5c405cbfdf67a71f5b45ba`.

- The saved-400167 exposure/recovery case lacked reviewer headroom because
  identical already-delivered source spans became duplicate claim pages.
  Exact-coordinate/file-version deduplication restored publication under its
  existing ceiling. The original test and allocation assertions are unchanged;
  seven new tests preserve identical text at different locations as distinct
  evidence.
- The saved-260340 source-funding case exposed an obsolete flat-note counter and
  duplicate whole source bodies in the writer projection. The new profile now
  sets that retired counter to zero, retains all four notes in the bound
  directory, and emits a covered source body once with an exact location pointer.
  Nonadjacent source outside the current excerpt remains present. Paid full
  excerpts, consumed units, reload/model-switch and immutable-receipt assertions
  remain enforced.

The audit also caught an unrelated 160-character ordinary-note restriction in
the new recall parser. Only explicit recall requests now have recall-specific
limits; the existing role contracts still govern ordinary notes. A real Gateway
test accepts a valid 327-character architecture gap under the original compact
note ceiling.

Receipt-only crash recovery is tested separately: when the bridge stops after
accepting a recall request but before saving flow state, the next compatible
execution recovers and applies the durable request. A later normal accepted
result supersedes it; foreign and quarantined requests cannot be revived.
The final focused retained-context suite has 26 passing tests. The broader
funding/consumer suite has 12 passing tests, and a combined saved-task/span/
publication/projection run has 26 passing tests. These counts overlap and are
not added together.
